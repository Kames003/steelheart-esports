# Steelheart Esports

Demo web študentského esportového projektu (VŠB-TUO, History of Esport).

**Live:** https://kames003.github.io/steelheart-esports/ · režim prezentácie: `#live`

Obsah: príbeh Ostrava × esport, analýza trhu a konkurencie, značka a slovník, 3D konfigurátor dresu, 4 divízie (CS2, LoL, Valorant, Dota 2), interaktívny ekonomický model, sponzorské balíčky, marketingové mockupy, Forge Cup, inovácie, riziká, živé hlasovanie s QR kódom a 44 zdrojov.
